JAVA LEARNING SYSTEM

JAVA学習ゲーム

問題を読んで、Javaの知識を身につけよう。

冒険の準備

5問ずつStageを進みます。どの出題方法でも5・10・15・20問から選べます。

学習状況・苦手特訓

問題の分類、Chapterごとの苦手問題、苦手特訓の記録を確認できます。

Chapterごとの学習状況

「苦手」または「超苦手」の問題を選びます。5問は1 Stage、10問は2 Stage、15問は3 Stage、20問は4 Stageです。対象が足りない場合は、同じ特訓で出した問題も繰り返し出ます。

苦手特訓の記録

サーバーから学習テーマを読み込んでいます。
